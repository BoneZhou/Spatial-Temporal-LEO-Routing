# ICC 2027 稿件用：四方法的觀測、動作與適配定義

更新：2026-10-22。本文比較 Proposed GAT-LSTM-DQN 與 GraphPR-adapted、FDR-MARL-adapted、DQN-IR-adapted (fixed-link)。後三者是依作者論文概念移植到本研究模擬器的版本，並非作者官方實作。以下定義以目前逐封包程式為準；四方法共享物理環境，但**不共享完全相同的觀測資訊**。

## 共同逐封包介面與可行動作

每筆路由決策帶有封包 ID、目前衛星 `i`、目的衛星 `d`、當前跳數與當前 20 ms slot 的真實可用鄰居。不同封包即使位於同一 `(i,d)` 也各自決策、產生自己的轉移（transition）。可行集合只包含當下存在的一跳星間鏈路（ISL）；無鏈路方向以動作遮罩（action mask）排除，不給任何方法額外路徑或未來拓樸。路由迴圈不額外以「曾拜訪節點」遮罩限制，而由共同的 30-hop TTL 處理。

Proposed 網路輸出 45 個衛星的 Q 值，動作是可行鄰居的**絕對衛星 ID**；其餘三方法各輸出四個固定**方向槽位**的 Q 值。槽位依序為同平面下一顆、上一顆，及跨平面兩個相鄰 plane 的候選（plane index 以 3 取模）；不存在的 ISL 遮罩。無論輸出編碼為何，實際路由都只能選相同模擬器給定的可用鄰居。貪婪決策的同分處理在 Proposed 取較小衛星 ID，三基線取較小槽位索引。正式測試關閉探索（`epsilon=0`）。

## 表 1：政策觀測向量（observation vector）

記 `x_j(t)` 為衛星 `j` 在 slot `t` 的三維位置，`q_j(t)` 為該衛星**單一共享佇列**內的封包數；軌道半徑 `R=6371+570=6941 km`，佇列上限 `Q=100`。下列座標與佇列皆為當前 slot 值，不使用未來流量／拓樸。

| 方法 | 每次決策的輸入、維度與正規化 | 時間／鄰居資訊及動作 |
|---|---|---|
| Proposed | 對 45 個衛星各給 6 維：`(x_j−x_d)/(2R)` 的 x/y/z 三值、`q_j/Q`、`||x_j−x_d||/(2R)`、`1{j=i}`；單一狀態為 `45×6`。 | 每封包保留最近 `T_w=5` 個狀態，形成 `5×45×6` 輸入；初次決策以第一個狀態重複填滿視窗，之後按該封包歷史更新。GAT 使用真實 ISL 與自迴路的鄰接遮罩；一個共享 GAT–LSTM 政策輸出 45 個 Q 值，只在當前一跳鄰居中選擇。**這包含全網 45 星的當前位置與 queue；不是純一跳觀測。** |
| GraphPR-adapted | 本地 7 維：plane index `/2`、同平面衛星 index `/14`、`x_i/R` 三值、`q_i/Q`、最近 50 slots 的本地 `q_i/Q` 均值。另接四槽鄰居前一時刻 hidden state `4×256`、四個槽位有效旗標，以及目的地／封包 6 維：目的 plane `/2`、目的星 index `/14`、`x_d/R` 三值、`q_i/Q`。總計 **1,041 維**。 | 45 組衛星獨立 agent；各 agent 用一層單頭本地注意力與四層 FCNN。只交換一跳鄰居 hidden state；缺鄰居之 hidden 向量為零且有有效旗標。每 slot 更新 hidden message，回合起點重置；四方向槽位動作。原論文的四條 per-ISL sending queues 不在本環境虛構出來。 |
| FDR-MARL-adapted | 前 4 維為 `x_d/R` 三值及 `q_i/Q`。每個四方向槽位 6 維：`(x_j−x_d)/(2R)` 三值、`q_j/Q`、`ERPD(j,d)/20 ms`、有效旗標；`ERPD=||x_j−x_d||/c`。缺邊全 0；總計 **28 維**。 | 45 組衛星獨立 DQN；三層 128 維 FCNN。僅本地、候選鄰居與目的地的當前資訊，不讀全網 queue；四槽位動作。原文 `9/14` 與 `14/14` 佇列閾值依比例映射到共用佇列的 **64/100** 與 **100/100**。 |
| DQN-IR-adapted (fixed-link) | 四槽位各 5 維：候選 `q_j/Q`、候選到目的地的環狀 grid 曼哈頓距離 `/8`、`1{j=d}`、固定傳輸時間與 slot 比 `0.04/20=0.002`、有效旗標；缺邊全 0。總計 **20 維**。 | 一組共享八層 residual Q 網路；四槽位動作。grid 距離＝plane 最短環距＋同 plane 15 星索引的最短環距，最大 8。環境沒有逐鏈路 SNR／可用頻寬，因此不造假這些原文特徵；固定 300 Mbps 鏈路只留下所有可行候選相同的傳輸項。 |

GraphPR 的一跳 hidden message、FDR 的一跳 queue／位置，以及 Proposed 的全網狀態**資訊取得成本不同**。目前比較只統一物理模擬器與外生流量；控制訊息與全網狀態取得的通訊成本未從 300 Mbps 鏈路容量扣除，不能稱「相同通訊開銷」或宣稱 Proposed 完全分散式部署已被證明。

## 表 2：學習訊號與策略差異

| 方法 | 非終止轉移獎勵（reward）的實作要點 | 終止與更新要點 |
|---|---|---|
| Proposed | 若下一跳更接近目的地給 `+1`，否則 `−1`，再減 `2·min(1,q_i/100)+0.1`。 | 成功 `+10`、丟棄 `−10` 覆寫非終止式；SmoothL1、target 每 200 updates；每封包獨立時間歷史。 |
| GraphPR-adapted | `0.6·RSPH − 0.55·(當跳 queue wait/20 ms) − 0.45·(當跳 propagation/20 ms)`；RSPH 由當前拓樸的 BFS 計算，遇到移除當前節點後無法到達目的地時設 `−30`。 | 成功 `+1`、丟棄 `−1`；SmoothL1、target 每回合更新；時間項正規化為本研究改動。 |
| FDR-MARL-adapted | 以候選 queue `q_j` 分段：`q_j≤64` 時權重 0.5，`65≤q_j<100` 時 0.05；再配合 `1000/(1+ERPD/20 ms)`，整式除以 1000，避免零延遲除零。滿佇列不預先移除真實 ISL；物理模型決定是否 drop。 | 成功按剩餘 TTL 給 `50·remaining_TTL/1000`，丟棄 `0`；MSE、target 每 500 updates。獎勵是公開適配式，非原文逐字重現。 |
| DQN-IR-adapted (fixed-link) | 非終止獎勵為 `−[0.4·0.002+0.4·(q_j/100)+0.1·(grid_distance/8)+0.1·H(h,18)]`，`H(h,18)=1/(1+exp(−(h−18)))`。 | 成功 `+1`、丟棄 `−1`；MSE、target 每 500 updates 或訓練中出現新最佳**已完成路徑** reward 時同步；18 是內部 soft hop penalty 中心，物理 TTL 仍為 30。 |

四個方法的 reward 尺度不同，**不可用 raw reward 跨方法排名**；正式方法比較只使用共同物理模擬器計算的吞吐量（throughput）、封包損失率（packet loss rate）、端到端延遲（end-to-end delay）及平均佇列長度（average queue length）。學習曲線只在各方法內檢查，不作跨尺度的 reward 大小比較。

**命名與界線**：三個外部方法的圖表標籤必須保留 `-adapted`，DQN-IR 保留 `(fixed-link)`；不能把本專案舊 `main.py`、`train_dqn.py` 或舊 2,000 回合單焦點消融結果重命名為這三個逐封包方法，也不能用舊消融聲稱已完成新版 Proposed 的嚴格模組消融。完整方法來源與原文差異見[基線適配規格](BASELINES.md)。
